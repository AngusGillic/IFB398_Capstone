# IFB398_Capstone

**Overview**
Travelly is a cross-platform mobile application designed to promote sustainable and healthier travel choices. The app encourages users to shift away from car-dependent transport and instead adopt environmentally friendly alternatives such as walking, cycling, and public transport. The application combines route planning, trip tracking, data analytics and personalised insights to influence user behaviour and support long-term sustainable habits.

Travelly is not just a navigation tool — it is designed to be a behavioural change platform that:
- Makes sustainable travel easier and more accessible
- Encourages long-term habit formation
- Provides users with actionable insights
- Balances functionality with strong privacy protections

This project involves developing selected features of the Travelly application as part of an academic capstone project. The focus is on building functional components that integrate into the overall system while demonstrating strong technical and design practices.

**Purpose of the Application**
Travelly aims to:
- Reduce reliance on high-emission transport methods
- Encourage environmentally sustainable travel behaviour
- Provide users with meaningful insights into their travel habits
- Support healthier lifestyle choices through active transport
- Deliver a privacy-focused user experience

**Core Functionality (Must-Have Features)**
Once fully implemented, Travelly will provide the following core capabilities:

**User Management**
- User registration and authentication
- Personalised user profiles
- Secure handling of user data

**Trip Planning & Navigation**
- Route suggestions using mapping services (e.g., Google Maps or OpenStreetMap)
- Integration with public transport data (e.g., TransLink GTFS)
- Multi-modal route planning (walking, cycling, public transport)

**Trip Tracking**
- Automatic or manual trip detection
- Recording of routes, distance, duration, and transport type
- Storage of user travel history

**Analytics & Insights**
- Visualisation of travel patterns and trends
- Calculation of:
  - CO₂ emissions saved
  - Calories burned
  - Distance travelled
  - User-friendly dashboards and charts

**Privacy & Data Protection**
- Privacy-first design principles
- Local processing where possible
- Secure storage and controlled data sharing

**Cross-Platform Mobile Experience**
- Built using Flutter, enabling deployment on both iOS and Android
- Consistent and responsive user interface across devices
